Overview

This prototype renders the Tekla Nest lightweight PySide6 design-system board from mockups.md. It covers foundation tokens, data-table patterns, forms and dialogs, toolbar/status behavior, accessibility/state coverage, and one representative shell composition without changing production code.

Primary flow

  1. Use foundation tokens for restrained engineering desktop presentation.
  2. Apply the data-table system to parts, stock, editable cells, filters, selection, and batch actions.
  3. Use dialogs and forms for activation, color schema, validation, blocking progress, and recovery.
  4. Use menu, toolbar, and status patterns for command access and persistent feedback.
  5. Validate keyboard paths, accessible names, high contrast, reduced motion, and reusable state coverage.
  6. Review the representative three-panel shell in a partial-result warning state.

Validation notes

  • All prototype screens use the same shell structure saved in docs/specs/_prototype-shell.html.
  • The prototype uses the selected modern SaaS/data-product palette; exact Tekla palette adoption remains Section 13 follow-up Q-025.
  • State examples pair color with text, labels, badges, or placement so meaning is not color-only.
  • Screen files are semantic vanilla HTML and import the shared styles.css file.
