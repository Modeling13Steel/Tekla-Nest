F05 - Accessibility and State Matrix

Accessibility and state matrix

Every reusable pattern must define state, recovery, focus, and announcement behavior.

Keyboard path

Menu bar -> toolbar actions -> parts panel -> parts table -> stock tabs/table -> report preview -> status recovery actions.

Accessible names

Use names such as Move bar row 3 up, Primary color #1d4ed8, and Comp. (mm), sorted ascending.

High contrast and motion

Use system colors in forced-colors mode. Feedback must not depend on animation.
