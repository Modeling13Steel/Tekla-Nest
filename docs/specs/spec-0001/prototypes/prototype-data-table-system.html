Prototype annotations

  • Related Section 13 IDs: Q-019, Q-020, Q-021, Q-024.
  • Filtering, sorting, selection, batch actions, and editable-cell validation are visible in one reusable table frame.
  • State behavior details are intentionally outside the UI frame: loading is triggered by import, empty by missing data, error by import failure, success by committed updates, disabled by unmet prerequisites, validation by invalid cell commits, permission by license-gated actions, and partial result by warning outcomes.
  • Recovery paths are load/import, retry, continue, complete prerequisites, correct value, activate license, or review affected rows; focus remains stable or moves to the first recovery target; announcements use the state copy shown in the frame.
