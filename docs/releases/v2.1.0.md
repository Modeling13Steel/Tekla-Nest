# Tekla Nest v2.1.0 — UI Refactor Release

**Date**: 2026-05
**Tag**: `v2.1.0`
**Type**: Minor (UX overhaul, no breaking API changes)

## Highlights

A 9-milestone UI refactor lands the new shell:

* **Design system** — typography, colour, spacing, motion, and dark
  theme tokens authored as a single source of truth
  (`src/tekla_nest/design_system/`).
* **AA contrast in both themes** — verified by automated tests
  (`test_dark_contrast.py`, body text ≥ 4.5:1, UI ≥ 3:1).
* **Dark mode + Preferences menu** — `Preferences → Theme` with
  System / Light / Dark; default is **Light**. Persisted to
  `~/.tekla_nest/preferences.json`.
* **Motion** — palette fade (120 ms), sidebar reveal (200 ms),
  KPI count-up (180 ms). All gated by `Preferences → Reduced
  motion`. Hard 200 ms cap enforced as `ValueError` in the helper.
* **Tables polish** — material chip filter, sticky filter bar,
  shared `TableFilterProxyModel`.
* **Insight sidebar + command palette + status bar polish.**
* **Shell slimmed** — `nest_window.py` from ~450 LOC at v2.0 to
  **314 LOC** at v2.1, with menu/i18n/preference logic extracted
  to dedicated modules.
* **Lint tightened** — ruff `select` now `E, F, W, I, B, UP, SIM`;
  Python target aligned to `py312`.

## Test surface

* **394** tests passing (up from 273 at v2.0.0).
* Ruff clean under tightened ruleset.
* LOC budgets enforced via `scripts/check_loc.py`.

## Upgrade notes

* No public API changes. Existing presenters, services, models
  unchanged.
* `AppConfig.prefer_reduced_motion: bool = False` is a new optional
  field; older `config.yaml` files load unchanged.
* `~/.tekla_nest/preferences.json` is created on first toggle of
  theme or reduced motion. Safe to delete — it'll regenerate.

## Known caveats

* The Preferences toggle for reduced motion takes effect immediately
  but the persisted value isn't yet re-read into `AppConfig` on next
  start (the file holds the choice; the next pass will layer it on).
* Baseline screenshots have not been re-captured for v2.1 (deferred:
  requires a manual display session).
